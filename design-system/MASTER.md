The user brief is authoritative. Independent creative studio; temporary wordmark STUDIO©. Natural US English. No client, award, or results claims. All project work is fictional and explicitly demo content.

## Direction

Cinematic editorial, expressive modern sans-serif, generous space, asymmetric photography. Near-black #0B0B0D, surface #171719, text #F5F4F0, muted #A6A6A8, paper #ECEAE5, restrained champagne #D9B783. Color comes from imagery. Use the supplied OVSoge sans throughout, paired with Retroscope Italic on selected headline words; Geist is a fallback. Keep small uppercase labels. 12-column editorial layout, max width 1440px; full bleed motion stages.

## Material

Original glass CSS borrowing only transferable Buki material principles: tinted control surfaces, 1px rim, inner top-left highlight, pointer reflection, soft shadow. Apply only to controls. No Buki branding or palette.

## Motion and access

Scroll-driven four-chapter narrative; stable headline intervals; staggered opposing card trajectories; reverse naturally. CSS 3D ring, damped momentum and snap. Native page scroll. Reduced-motion shows all service chapters in normal document flow, static marquee and instant gallery navigation. Semantic native dialog, focus restoration, keyboard controls, visible focus. Minimum 44px controls.

## Skill review

ui-ux-pro-max design-system search verified scroll storytelling and spacious hierarchy as applicable. Its broad Brutalism / Apple Liquid Glass style matches were unsuitable as complete systems, so the explicit supplied palette, typography and cinematic direction override those recommendations. Focused Next.js image guidance and keyboard-focus guidance were used.
